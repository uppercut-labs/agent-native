# E09 standalone project

Install dependencies with npm ci, then run npm test and npm start. npm test builds the inline MCP App resource and exercises an official SDK App/AppBridge host fixture against a loopback MCP server. npm start prints the ordinary text and structured result for a non-UI host.

The project is a local conformance fixture. It does not deploy a server or claim real-host/browser acceptance. See the parent example README and docs/mcp-apps.md.
