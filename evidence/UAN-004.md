## Implemented slice

The `@uppercut-labs/agent-native/cli` runner subpath and the installed E05/E12 application CLIs accept an application registry, explicit authorization
port, caller, stream adapter, and optional named credential profiles. It generates help and simple
typed flags from registered input schemas; structured inputs use `--input-json` or
`--input-json -`. Invocation requires explicit `--mode local|remote`. Remote mode requires an
own-property credential profile, an HTTPS URL (or explicit loopback HTTP fixture), a non-empty token,
and a bounded timeout. Remote output is validated against the capability output schema. Local mode
uses the shared executor. The remote mode rejects `--binding-id` instead of ignoring it.

Machine invocations emit one JSON envelope conforming to the exported
`CLI_RESULT_JSON_SCHEMA`/`uan.cli-result/v1` on stdout. Effective target and redacted errors go to
stderr. The library CLI code does not launch child processes or a shell. Tests launch the example
using Node's argument array with `shell: false`.

E05 is an independently installed album-lookup CLI fixture with a real loopback HTTP adapter server.
Its success values match for local and remote runs. No package-level `bin` command or global `agent-native` executable ships in this slice. It also tests invalid input/stdin, unavailable
credentials, unknown versions, shell metacharacters in a value, a cwd with spaces, ignored-abort
fetch timeout, remote output validation, unsafe URL/profile cases, ignored remote binding ID, and a
redacted server handler failure. E12 now exercises the same installed CLI with typed number and enum
flags plus a structured invalid-input result.

## Limits

The remote example runs against a local loopback server, not a deployed network host or external
credential provider. E05 adapts the HTTP handler using Node's built-in server; it does not claim Hono
integration. Only the research host runtime was exercised (Node 25.9.0); Node 22 minimum-version and
cross-platform UAN-022 execution remain unverified. HTTP remains limited to the public-read surface.
Remote timeouts abort cooperative fetchers and return on deadline even for a fetcher that ignores the
abort signal; the underlying ignored fetch operation itself cannot be forcibly terminated.
