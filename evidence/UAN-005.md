# UAN-005 - Official MCP adapter evidence

## Scope

This evidence covers a fixture-tested adapter slice in the private package source at version
0.0.0. package.json remains private: true. Local verification, including the tarball dry run, ran before any release action.
The public package entry is isolated at @uppercut-labs/agent-native/mcp, and the package tarball
dry run includes dist/mcp.js and docs/mcp.md.

The adapter uses @modelcontextprotocol/server@2.3.0 at runtime and
@modelcontextprotocol/client@2.3.0 only for development fixtures. The official client and server
exchange ran over a local Node.js 25.9.0 HTTP socket and negotiated MCP protocol version
2025-11-25. This establishes fixture behavior for that pair and environment, not broad client or
host compatibility.

## Checks

Run from the repository root:

- npm run check - passed: format, lint, type checks, browser proof, library tests, and E01/E12/E05
  standalone example checks. Library tests: 44 passed; E01: 3 passed; E12: 5 passed; E05: 8 passed.
- npm pack --dry-run --json - passed. Tarball preview: uppercut-labs-agent-native-0.0.0.tgz,
  56 files. It contains dist/mcp.js, dist/mcp.d.ts, docs/mcp.md, and docs/compatibility.md.
  This command did not publish the package.
- npm ls --depth=0 - passed. Both MCP SDK packages resolve to exact version 2.3.0.
- node --test test/mcp.test.mjs - passed: 7 tests over a real local HTTP socket.

The MCP fixture exercised:

- Official client initialize, tools/list, and tools/call; discovered the expected public-read
  album lookup tool; validated structuredContent.result with the canonical output schema.
- Protocol version observed through Client.getNegotiatedProtocolVersion() as 2025-11-25.
  The fixture then constructed a diagnostic observation from that verified exchange; the adapter
  itself does not emit diagnostics.
- Malformed protocol body returned HTTP 400; oversized body with a 1,024-byte configured cap
  returned HTTP 413.
- Invalid tool input returned an MCP tool error without exposing the invalid value.
- Protected destructive tools and per-request filtered public tools were absent from discovery;
  direct calls by hidden names failed without invoking their bindings.
- Per-request authorization denial of a discovered public tool returned a not-found style tool
  error without invoking its binding.
- Non-JSON top-level values including undefined and BigInt returned redacted tool errors.
- Tool identifiers remained distinct for tested namespace/name pairs containing separators.

## Limits

This slice does not establish full E01/E04/E05 retrofit coverage. The sample album domain appears
in the adapter fixture; no Cloudflare Workerd route or E04 host is claimed. E05's existing CLI and
HTTP examples are covered by its independent checks, not by an MCP client integration. Framework
mount behavior, OAuth authorization-server interoperability, production deployment, rate limiting,
physical hosts, commercial MCP clients, and Node versions other than the local test host remain
unverified. Host integrations must enforce transport security and authentication and should apply
request-size limits before buffering request bodies. Capability handlers must observe the AbortSignal
to stop work after the configured deadline.
