# UAN-001 local evidence

Status: local baseline verified; no npm publication or MCP protocol/host compatibility claim.

## Environment and upstream baseline

Exact versions and primary-source links are in [VERSION-EVIDENCE.md](../VERSION-EVIDENCE.md).
The official MCP TypeScript server SDK is a dev-only dependency for one type-boundary fixture.
The source and the contract core do not import it at runtime. No MCP exchange was attempted.

## Reproduction

Run from the repository root:

```sh
npm ci
npm run check
npm pack --dry-run --json
```

`npm run check` runs format, lint, source/browser/upstream typechecks, the package build and tests,
then exports E12 with a freshly packed local tarball, generates a standalone lockfile, runs
`npm ci` in the exported project, and runs the example's tests. The generated example lives at
`examples/e12-shared-unit-converter/.exported` and has no workspace alias.

## Evidence boundaries

- Zod parsing and Ajv validation cover album lookup and unit converter input/output shapes.
- The nonportable transform fixture fails JSON Schema projection explicitly.
- The core-only contract fixture typechecks with ES2022 and no Node or DOM declarations. The
  runtime smoke test removes those globals for the contract module import; this is not a browser
  engine or host compatibility test.
- Diagnostics serialize and validate passed, failed, and unknown states against the exported
  JSON Schema, with no free-form payload field.
- The SDK boundary fixture verifies its upstream `any` source type, stores the value as `unknown`,
  and rejects a wrong value through runtime validation.
- No remote MCP handshake, authorization, WebMCP, MCP Apps, generated HTTP/OpenAPI, CLI product
  surface, framework installer, or deployment integration is implemented here.
