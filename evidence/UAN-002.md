# UAN-002 local execution evidence

Status: local acceptance demonstrated for the definition, binding, registry, executor, and E01/E12
example slice. The package remains private at `0.0.0`; no npm publication or transport/host claim is
made.

## Reproduction

Run from the repository root with the pinned Node/npm versions in [VERSION-EVIDENCE.md](../VERSION-EVIDENCE.md):

```sh
npm ci
npm run check
npm pack --dry-run --json
```

`npm run check` includes format, lint, core/browser/upstream typechecks, browser-proof compilation,
unit tests, and fresh tarball export/install/test/CLI checks for E01 and E12. The tests exercise
the compiled package, not a workspace alias.

## Acceptance evidence

- `test/executor.test.mjs`: handler-free definition registration; malformed identity and missing
  definition; missing binding; named album missing outcome; repeated authorization checks; denied
  handler not called, including a request with no authorization port; invalid handler output;
  duplicate definition diagnostic; ambiguous runtime selection and explicit `bindingId`; server
  binding unavailable in browser; invalid-schema observation; and required access metadata.
- `src/core/contracts.ts`, `src/core/registry.ts`, `src/core/executor.ts`: explicit risk/access,
  immutable canonical identity, exact runtime selection, input/auth/handler/output ordering, and
  structured failures with stable observations.
- `test/fixtures/server-secret-binding.mjs` plants a fake sentinel used only by a server-targeted
  test binding. `tsconfig.browser-proof.json` compiles the contract fixture without DOM or Node
  declarations; the package and browser outputs are scanned to confirm the sentinel is absent.
- `examples/e01-album-catalog/project`: independently installed album lookup, found/missing
  outcomes, and a malformed-slug negative fixture.
- `examples/e12-shared-unit-converter/project`: independently installed conversion fixtures,
  explicit local binding, and invalid-unit/non-finite negative paths.
- `docs/capabilities-and-bindings.md` freezes the public v0 authoring signatures and explains
  authorization and runtime-selection behavior.

## Verification boundary

The examples run on the pinned local Node runtime. E01 here is only its domain and local-execution
slice; Astro static generation, browser registration, a server sidecar, MCP, HTTP/OpenAPI, WebMCP,
MCP Apps, and real-host compatibility were not implemented or tested. The required authorization
port is an integration seam; durable grants, identity systems, and policy stores remain adopter
responsibilities. The fake sentinel test protects owned compiled outputs and is not a full bundler
or browser-engine test. SDK presence does not establish MCP protocol conformance.
